# ClassMate Context

## UX targets
- DM: WhatsApp-quality
- Classroom chat: WhatsApp group-quality
- NOVA: ChatGPT-quality

## Messaging rules
- Preserve message ordering correctness
- Preserve date chips correctness
- Preserve reply flows
- Preserve pinning
- Preserve reactions
- Preserve voice notes
- Preserve media sending
- Preserve request approval boundaries

## Forwarding rules
- Shared forward picker if possible
- Classrooms section first
- DMs section second
- Classroom order must match existing classroom custom order
- DMs sorted by recency
- Only approved targets
- Support single and multi-message forwarding
- Selection mode should mirror delete-selection feel

## Engineering rules
- Incremental
- Predictable
- Launch-minded
- No hidden regressions
