# Permissions Matrix (SSOT)

Legend: R=read, W=write

## Admin
- Manage cohorts/courses/schedule: R/W
- Manage announcements: R/W
- Moderate solutions: R/W
- View all: R

## Teacher
- Attendance: R/W
- Grades: R/W
- View own cohorts: R
- Post course announcements (if allowed): W

## Student
- View schedule/grades: R
- Tutor + brain: R/W (own)
- Solutions: R/W (own), R (others)

## Parent
- Link child: W
- View child: R (schedule/grades/attendance/announcements)
- Notifications: R/W (mark seen)

## Secretary
- Announcements: R/W
- (Optional) schedule overrides: R/W
