Frequently asked

Which languages does ClassMate support?

English, Hebrew, Arabic, Russian and French — fully translated, including right-to-left layouts.

Who is ClassMate for?

Students, teachers, parents, secretaries and admins — each gets a tailored experience in the same app.

Can I use it without installing?

Yes — open the web app in any browser. For the full experience (notifications, payments) install the mobile app.

Is it free?

Core school features are included; NOVA tutor offers a generous free tier with optional plans.
